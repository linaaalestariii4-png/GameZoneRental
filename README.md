GameZone Rental PS

Deskripsi
GameZone Rental PS adalah program sederhana berbasis Java untuk menghitung biaya penyewaan PlayStation 4 dan PlayStation 5.

 Fitur
- Memasukkan nama pelanggan.
- Memilih PlayStation 4 atau PlayStation 5.
- Memasukkan lama bermain.
- Memilih tambahan minuman.
- Menghitung biaya sewa dan diskon 10% untuk durasi minimal 3 jam.
- Menampilkan struk pembayaran.
- Melakukan transaksi berulang.

 Teknologi
- Bahasa pemrograman Java
- Apache NetBeans
- Maven

Cara Menjalankan
1. Buka proyek GameZone Rental PS di NetBeans.
2. Buka file `GameZoneRental.java`.
3. Jalankan program.
4. Masukkan data pelanggan sesuai petunjuk pada layar. GameZone Rental PlayStation
