 GameZone Rental PlayStation

 Deskripsi
GameZone Rental adalah program Java untuk menghitung biaya penyewaan PlayStation 4 (PS4) dan PlayStation 5 (PS5).

 Fitur Program
- Memasukkan nama pelanggan.
- Memilih PS4 atau PS5.
- Menghitung biaya sewa berdasarkan lama penyewaan.
- Menambahkan biaya minuman.
- Memberikan diskon 10% untuk penyewaan minimal 3 jam.
- Menampilkan total pembayaran.
- Menampilkan struk pembayaran.
- Mengulangi transaksi pelanggan.

Daftar Harga
- PS4: Rp8.000 per jam.
- PS5: Rp12.000 per jam.
- Minuman: Rp5.000.
- Diskon: 10% untuk penyewaan minimal 3 jam.

 Teknologi
- Java
- Apache Maven
- NetBeans IDE

 Cara Menjalankan
1. Buka proyek GameZoneRental di NetBeans.
2. Jalankan file GameZoneRental.java.
3. Ikuti petunjuk yang muncul pada terminal.
